# DeliveryApp

Мини-сервис доставки еды. Проект на SwiftUI, MVVM.

## Сборка
1. Откройте `DeliveryApp/DeliveryApp.xcodeproj` в Xcode 16.
2. Соберите и запустите на iOS 16+.

## MockMode
По умолчанию `API_BASE_URL` в `Resources/Info.plist` пустой, поэтому используется режим моков:
- платежи через СБП эмулируются ссылкой `app://mockpay` и через ~3–5 сек помечаются как *PAID*;
- заказ хранится в памяти и проходит статусы до доставки;
- отправка в Telegram — заглушка (лог).

Для работы с реальным бэкендом укажите `API_BASE_URL` в `Info.plist`.

## Конфигурация
- `API_BASE_URL` — базовый URL API.
- `PAYMENT_RETURN_URL` — URL, на который вернётся пользователь после оплаты. Добавьте схему в разделе *URL Types* настроек проекта.
- `NSLocationWhenInUseUsageDescription` — причина запроса геолокации.

## Оплата СБП через ссылку
Приложение открывает внешнюю ссылку/payLink в СБП. Это допускается для оплаты физических товаров: оплата происходит в приложении банка, после чего заказ подтверждается.
